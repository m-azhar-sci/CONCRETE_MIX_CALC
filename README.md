# Concrete Mix Calculator

A simple Python script that calculates the weight of ingredients needed to prepare a concrete mix.

## What it does
Given a required mix weight ratio and volume of concrete needed, the script calculates the quantities of cement, sand, and aggregate needed.

American Standard ASI 318 was used in this calculator

## Requirements
- Python 3.x

## How to run
```
python CONCRETEMIXER.py
```
